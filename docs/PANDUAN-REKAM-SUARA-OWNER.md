# Panduan rekam "Suara owner" (R31, 16 Nov 2026)

Rekaman ini dipakai untuk melatih satu profil suara: **Suara owner**. Profil itu dipakai mesin untuk voice over iklan:

1. Naskah dibacakan dulu oleh suara Windows berbahasa Indonesia.
2. Hasilnya diubah menjadi suara owner lewat model konversi suara (RVC/Applio, lisensi MIT).

Profil ini hanya untuk suara owner sendiri. Menambah suara orang lain perlu keputusan owner.

## Yang dibutuhkan
| | |
|---|---|
| **Durasi** | **10–15 menit** suara bersih. Minimal 5 menit, tetapi hasilnya akan kurang mirip. |
| **Alat** | HP biasa sudah cukup. Pakai aplikasi perekam suara bawaan, bukan voice note WhatsApp, karena WhatsApp memampatkan suara. |
| **Format** | WAV, atau M4A/MP3 dengan kualitas tertinggi. Kirim file aslinya, jangan lewat chat yang memampatkan file. |
| **Tempat** | Ruangan **sunyi** dan **tidak bergema**, misalnya kamar dengan kasur, lemari baju, atau gorden. Jangan di kamar mandi atau ruangan kosong. |
| **Posisi HP** | ±15–20 cm dari mulut, sedikit di bawah dagu supaya napas tidak meniup mikrofon. Jarak dijaga sama dari awal sampai akhir. |
| **Suara latar** | Matikan kipas, AC yang berisik, TV, dan musik. Jangan ada orang lain yang bicara. |

## Cara membaca
- Bicara seperti sedang live atau bikin konten, bukan seperti membaca berita. Gaya ini yang ingin ditiru di iklan.
- Rekam 3 bagian, boleh dalam file terpisah:
  1. **Naskah di bawah, dibaca santai** (±6 menit).
  2. **Naskah yang sama, dibaca semangat** seperti jualan saat live (±6 menit).
  3. **Bicara bebas 3 menit** tentang produk favorit, tanpa naskah.
- Salah ucap tidak apa-apa. Cukup berhenti 2 detik lalu ulangi kalimatnya.
- Jeda antar kalimat normal saja. Jangan berbisik, jangan berteriak.
